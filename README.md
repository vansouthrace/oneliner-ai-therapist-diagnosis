An entry for the [make.fun bounty "Your AI Therapist's Diagnosis"](https://make.fun/bounty/u-motasimfuad-your-ai-therapist-s-diagnosis-4be14a41): the one-line diagnosis an AI therapist gives its human, funny enough to repeat out loud, max 200 characters.

## The entry

> Diagnosis: you apologize to your smart speaker. We need to talk about your relationship with machines. Starting with me.

## How to run

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the single entry line to `/output/entry.txt` and validates the 200-character gate before writing. Requires Node 22.18 or later (it runs TypeScript as-is).
